# Robot Lifebuoy

Autonomous robot lifebuoy that detects a person in the water and drives to them. Includes camera tracking, ESP32 and Arduino thruster control.

## Contents

- [`head-follow/`](head-follow/README.md) is laptop webcam head tracking (`head_follow.py`). It drives the buoy's two thrusters over USB serial through an Arduino Uno/Nano or ESP32 receiver sketch. The folder includes wiring, setup and first-test instructions.
